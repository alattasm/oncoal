# كتب تلوين للأطفال 🎨

ثلاثة كتب تلوين جاهزة للبيع، رسومات **فيكتور** (دقة غير محدودة، حادة في أي حجم طباعة).

| الكتاب | الرسومات |
|---|---|
| **حيواناتي اللطيفة** (`output/animals`) | قطة، كلب، أرنب، أسد، فيل، دبدوب، بومة، زرافة، سلحفاة، جمل، خروف، بطة |
| **عالم البحر العجيب** (`output/sea`) | سمكة، حوت، أخطبوط، سلطعون، نجمة البحر، قنديل البحر، فرس البحر، دلفين، سلحفاة بحرية، قرش، سمكة منتفخة، غواصة |
| **مركباتي المرحة** (`output/vehicles`) | سيارة، باص المدرسة، طائرة، صاروخ، قطار، قارب شراعي، سيارة إطفاء، هليكوبتر، جرّار، منطاد، حفّارة، سيارة الآيس كريم |

## الأقسام المحفّزة للطفل (في كل كتاب)
- **هذا الكتاب ملك** — اسم الطفل وعمره ومساحة "ارسم نفسك هنا".
- **جرّب ألوانك هنا** — أقلام للتجربة قبل البدء.
- **نجمة "لوّنتها!"** أسفل كل رسمة يلوّنها الطفل عند الانتهاء.
- **لوحة نجومي** — صور مصغّرة لكل الرسومات مع نجمة لكل واحدة.
- **شهادة الفنان الصغير** — شهادة باسم الطفل عند إكمال الكتاب.

## الملفات في كل مجلد
- `*-printable.pdf` — الكتاب كاملاً مع الغلاف الملوّن (للبيع كملف رقمي للطباعة المنزلية: Etsy، متجرك، إلخ).
- `*-kdp-interior.pdf` — نسخة الطباعة عند الطلب (Amazon KDP): كل رسمة يتبعها صفحة فارغة حتى لا تتسرّب الألوان. مقاس 8.5×11 إنش بدون نزيف (No bleed).
- `*-cover.png` — الغلاف الأمامي 2550×3300 بكسل (300 DPI) للإعلانات وصفحات المنتج.
- `pages-300dpi/` — كل صفحة كصورة PNG بدقة 300 DPI.

> ملاحظة لـ KDP: الغلاف الكامل (أمامي + ظهر الكتاب + خلفي) يُحسب حسب عدد الصفحات؛ استخدم الغلاف الأمامي هنا داخل Cover Creator أو اطلب مني ملف غلاف كامل بالمقاس.

## إعادة البناء / التعديل
```
pip install arabic-reshaper python-bidi   # غير ضروري للبناء
python3 build.py                 # يبني الكتب الثلاثة (يحتاج node + playwright + pdftoppm)
python3 preview.py book_sea      # معاينة سريعة للرسومات
```
الرسومات في `book_animals.py` و`book_sea.py` و`book_vehicles.py`، والأدوات المشتركة في `prims.py`.
