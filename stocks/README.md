# بوت منهج الأسئلة الثلاثة

أداة تعليمية تحلل أي سهم على Yahoo Finance بمنهج القراءة اللي يشرحه المحلل
أسعد حمزة (قناة Assad Hamzeh على يوتيوب). البوت غير تابع له.

## ماذا يفعل البوت
1. **مين الغالب؟** يحدد حالة السوق من القمم والقيعان: صاعد، هابط، أو عرضي.
2. **قديش غالب؟** يقارن خطوات التيران بخطوات الدببة في آخر 20 شمعة.
3. **هل الغلبة عم تتغير؟** يبحث عن تعب الاتجاه: خطوات أصغر، ذيول أطول، قمة أو قاع بالكاد يتجاوز السابق.
4. **مناطق الدعم والمقاومة:** يرسمها كمناطق وليس كخطوط.
5. **قراءة الاختراق:** يعتمد على إغلاق الشمعة لا على الذيل، ويحذّر من الاختراق الكاذب.
6. **شرط الدخول على فريم الساعة:** إغلاق شمعة ساعة فوق آخر قمة صغيرة.
7. **حسبة الصفقة:** يحدد الوقف أولاً، ثم يحسب عدد الأسهم من مبلغ المخاطرة، والهدف عند 2.5 ضعف المخاطرة، مع الخروج المقسّم.
8. **مراجعة مركز قائم:** إذا أعطيته سعر شرائك.
9. **تحذير السيولة:** ينبّهك إذا كانت سيولة السهم ضعيفة.

## التشغيل
```bash
pip install pandas numpy
python3 assad_bot.py IVN.TO
python3 assad_bot.py CBLU.V --cost 0.06 --risk 50
python3 assad_bot.py VWAV XNDU.TO --risk 100 --cost 0.45 --shares 2000
```

| الخيار | المعنى |
|---|---|
| `--risk` | المبلغ الذي تقبل أن تخسره في الصفقة |
| `--cost` | سعر شرائك |
| `--shares` | عدد أسهمك |

> أداة تعليمية، وليست توصية مالية. القرار في السوق مسؤوليتك.
