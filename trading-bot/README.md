# بوت تداول الأسهم والعملات — Smart Money + RSI + Grid

بوت مبني على قواعد الفيديوهات الثلاثة:

| الفيديو | الفكرة | كيف طبّقناها في البوت |
|---|---|---|
| ١ — RSI فوق 70… يعني بيع؟ | فوق 70 مو إشارة بيع، يعني الصعود قوي. انتبه للتباعد (السعر قمة أعلى و RSI قمة أقل) وانتظر تأكيد من السعر | البوت **ما يبيع أبداً لأن RSI فوق 70**. فلتر اختياري (مفعّل افتراضياً): لازم يكون فيه تباعد RSI عند سحب السيولة، والدخول ما يصير إلا بعد كسر الهيكل |
| ٢ — ليش المحترفين يبيعون فوق القمة | سحب سيولة ← تغيّر سلوك CHoCH ← كسر هيكل BOS ← فجوة FVG ← دخول عند الرجوع | نفس الخطوات بالضبط (تحت) |
| ٣ — بوت يتداول عنك بدون كود | ملف MQ5، أزرار تشغيل/إيقاف، حجم الصفقة، المسافة بين الأوامر، بوت قريد، اختبار على Strategy Tester وحساب تجريبي | ملف `mt5/SMC_RSI_Bot.mq5` فيه لوحة تحكم + وضع Grid + وقف خسارة |

## قواعد الاستراتيجية (البيع — والشراء عكسها بالضبط)

1. **سحب سيولة**: شمعة تطلع فوق قمة سابقة (Swing High) بس **تسكّر تحتها** (ذيل بس). لو سكّرت فوقها = كسر هيكل حقيقي، مو سحب.
2. **CHoCH (تغيّر سلوك)**: السعر يسكّر تحت القاع المحمي (آخر قاع قبل السحب) — هذا **تنبيه مو دخول**.
3. **BOS (كسر هيكل)**: السعر يسوي قمة أدنى، بعدها يسكّر تحت القاع الجديد.
4. **FVG (فجوة)**: النزول القوي يترك فجوة بين ثلاث شموع (قاع الشمعة الأولى أعلى من قمة الثالثة).
5. **لا تلحق الشمعة**: انتظر السعر يرجع للفجوة، يرفضها، ويسكّر تحتها بشمعة هابطة ← **دخول**.
6. **الستوب** فوق ذيل السحب، **الهدف** = ٢ × المخاطرة (R:R 1:2، تقدر تغيره).
7. لو السعر سكّر **فوق الفجوة** ← الفكرة ملغية.
8. **RSI**: لازم يكون فيه تباعد هابط عند السحب (قمة سعر أعلى + قمة RSI أقل). تقدر تطفيه من الإعدادات.

## ١) بوت MetaTrader 5 (الأسهم، الفوركس، الذهب، الكريبتو)

**التركيب:**
1. افتح MT5 ← `File` ← `Open Data Folder` ← `MQL5` ← `Experts`.
2. انسخ الملف `mt5/SMC_RSI_Bot.mq5` داخل مجلد `Experts`.
3. افتح MetaEditor (F4) ← افتح الملف ← اضغط `Compile` (F7).
4. ارجع لـ MT5 ← اسحب البوت من `Navigator > Expert Advisors` على الشارت ← فعّل `Allow Algo Trading`.
5. بتطلع لك **لوحة البوت** على الشارت:
   - زر **START** (تشغيل) وزر **STOP** (إيقاف)
   - **Lot size**: حجم الصفقة
   - **Distance between orders**: المسافة بين الأوامر بالنقاط
   - الحالة، عدد الصفقات، الربح/الخسارة

**أهم الإعدادات:**

| الإعداد | الافتراضي | الشرح |
|---|---|---|
| `Strategy` | Smart Money + RSI | أو `Grid` (بوت السلّم من الفيديو ٣) |
| `Lot size` | 0.01 | حجم الصفقة الثابت |
| `Risk %` | 0 | لو حطيت مثلاً 1 ← يحسب الحجم بحيث الخسارة عند الستوب = 1٪ من الرصيد |
| `Distance between orders` | 300 | في Grid = المسافة بين الدرجات. في SMC = أقل مسافة بين صفقتين |
| `Require RSI divergence` | true | فلتر الفيديو ١ |
| `Wait for BOS` | true | الفيديو ٢: CHoCH تنبيه بس، ننتظر BOS |
| `Reward : Risk` | 2.0 | الهدف = ضعف الستوب |
| `Max drawdown %` | 10 | **إيقاف طوارئ**: يقفل كل الصفقات ويوقف البوت لو الحساب نزل 10٪ |
| `Grid levels / TP / SL` | 5 / المسافة / بدون | إعدادات وضع السلّم |

> البوت يشتغل على **الشموع المغلقة فقط** (مرة وحدة كل شمعة جديدة)، فما يرسم إشارة ويمسحها.
> الفريم المقترح: ساعة أو ٤ ساعات.

**الاختبار قبل أي فلوس حقيقية (مثل ما قال الفيديو):**
`View` ← `Strategy Tester` ← اختر `SMC_RSI_Bot` ← الرمز والفريم ← `Modelling: Every tick based on real ticks` ← `Start`.
في التستر البوت يشتغل تلقائي (الأزرار ما تشتغل في التستر). بعدها جرّبه أسبوعين على **حساب تجريبي**.

## ٢) أدوات بايثون (اختبار + ماسح إشارات للأسهم والكريبتو)

```bash
cd trading-bot/python
pip install -r requirements.txt

# اختبار تاريخي
python backtest.py --source kraken --symbol XBTUSD --tf 1h          # بيتكوين
python backtest.py --source yahoo  --symbol AAPL   --tf 1h          # أبل
python backtest.py --source yahoo  --symbol 2222.SR --tf 1d         # أرامكو
python backtest.py --source yahoo  --symbol GC=F   --tf 1h --trades # الذهب + كل الصفقات

# ماسح: وين طلعت إشارة في آخر الشموع
python scan.py --tf 1h
python scan.py --yahoo 2222.SR 1120.SR 7010.SR --kraken XBTUSD ETHUSD --tf 1d
```

نفس القواعد بالضبط في بايثون و MQL5 (تأكدنا إن الإشارات متطابقة 100٪ على نفس البيانات).
